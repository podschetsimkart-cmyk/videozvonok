# Видеозвонок

Видеовстречи в браузере: камера, микрофон, показ экрана, чат. Без регистрации и установки.

**Как пользоваться:** открыть сайт → «Создать встречу» → «Пригласить» → отправить ссылку участникам.

- До 6 человек в комнате (каждый соединён с каждым напрямую, mesh WebRTC).
- Поиск собеседников — бесплатный облачный сервер PeerJS (`0.peerjs.com`), обход NAT — STUN Google/Cloudflare.
- Показ экрана работает на компьютере (Chrome, Edge, Firefox, Safari); на телефонах браузеры его не дают.
- Своего TURN-сервера пока нет: если двое сидят за «строгим» NAT (часть мобильных сетей), видео может не дойти.
  TURN добавляется в `PEER_OPTIONS.config.iceServers` в `app.js`.

Файлы: `index.html`, `style.css`, `app.js`, `vendor/peerjs-1.5.5.min.js` (PeerJS, MIT). Сборки нет — статика.

Локально: `python -m http.server 8765` и открыть `http://localhost:8765`.
